## 🎬 Grok Imagine Content Creation Brief

### Project: Apex Omnis Studios Visual Identity

**Objective:** Create cinematic visual content to establish brand presence and drive engagement

---

### Deliverable 1: 30-Second Cinematic Shorts (5 videos)

**Theme:** "Preserve the Heart" - Anti-extraction philosophy in action

**Video Concepts:**

1. **"The Collector"** (30 sec)
   - Opening: Close-up of hands carefully placing a rare TCG card in a binder
   - Mid: Zoom out to reveal a constellation background (matching website aesthetic)
   - Message: "Not for extraction. For preservation."
   - CTA: "Track what matters. Apex Omnis Studios."

2. **"The Bubble"** (30 sec)
   - Opening: Animated price chart going vertical (hype cycle)
   - Mid: Chart pops like a bubble, cards scatter
   - Message: "When the money gets too big, the heart is lost."
   - CTA: "Real intelligence. No hype. Apex Omnis."

3. **"The Algorithm"** (30 sec)
   - Opening: Matrix-style code rain (sentiment analysis)
   - Mid: Code resolves into a single card with sentiment score
   - Message: "X platform data. Real-time truth."
   - CTA: "Grok-powered TCG intelligence."

4. **"The Challenge"** (30 sec)
   - Opening: Stopwatch ticking, cards being sorted rapidly
   - Mid: Leaderboard appears with top times
   - Message: "Can you beat the best?"
   - CTA: "Challenge Mode. Prove it."

5. **"The Mission"** (30 sec)
   - Opening: Montage of tools (Portfolio Tracker, Event Tracker, Challenge Mode)
   - Mid: Constellation animation connects them all
   - Message: "Tools that preserve. Not extract."
   - CTA: "Apex Omnis Studios. Built different."

**Style Guide:**
- Dark theme with cyan/purple/yellow accents (match website)
- Constellation animation background (signature aesthetic)
- Clean, modern typography
- No red colors (reserved for cybersecurity division)
- David Foster Wallace influence: complexity over simplification

**Format:**
- 1080x1920 (vertical for Instagram/TikTok)
- 30 seconds max
- Subtitles included (accessibility)
- Background music: ambient/electronic (no vocals)
